# Gait Phase Classification

[Back to Projects](../projects.md) · [Back to README](../README.md)

A reproducible temporal modeling pipeline for four operational states, P0–P3, using CASIA-C thermal silhouettes.

## What I Built

- Data inventory, provenance checks, and annotation QA
- Subject-independent folds and held-out evaluation safeguards
- Temporal models, attention, baselines, and reproducible experiment workflows
- Subject-level reporting and manuscript assets

## Status and Evaluation

Current deterministic labels are provisional. Agreement with the labeling rule does not independently validate anatomical gait phases or same-foot continuity. Publication claims require expert annotation and adjudication, leakage-controlled evaluation, and completed experiments. Dataset preparation is required separately from cloning the source.

## Technology

Python, PyTorch, temporal modeling, attention, CASIA silhouettes, data QA.
